- **가이드 페이지** (`/guide`)

## 📈 SEO 성과 측정 지표

### 1. 검색 엔진 지표
- **검색 노출 횟수** (Impressions)
- **클릭 수** (Clicks)
- **클릭률** (CTR)
- **평균 순위** (Average Position)
- **노출 키워드 수**

### 2. 사용자 행동 지표
- **유입 트래픽**
- **이탈률** (Bounce Rate)
- **체류 시간** (Avg. Session Duration)
- **페이지뷰/세션**
- **전환율** (상담 신청)

### 3. 페이지별 목표 지표

| 페이지 | 주요 지표 | 목표 |
|--------|----------|------|
| 메인 | 유입 트래픽 | 월 10,000+ |
| 진단 | 체류 시간 | 평균 3분+ |
| 계산기 | 사용 완료율 | 70%+ |
| 상담 | 전환율 | 5%+ |
| 블로그 | 페이지뷰 | 월 20,000+ |

## 🔧 기술적 SEO 최적화

### 1. 메타데이터
```typescript
// lib/metadata.ts
export const defaultMetadata = {
  title: { default: '이혼준비', template: '%s | 이혼준비' },
  description: '...',
  keywords: [...20개 핵심 키워드],
  openGraph: { ... },
  twitter: { ... },
  robots: { index: true, follow: true }
}
```

### 2. 구조적 데이터 (JSON-LD)
- **Organization** - 조직 정보
- **WebSite** - 웹사이트 정보
- **FAQPage** - FAQ 구조
- **Article** - 블로그 포스트

### 3. 사이트맵
- **정적 페이지** - 8개
- **동적 블로그 포스트** - 자동 추가
- **캐싱** - 24시간 재검증

### 4. robots.txt
- 크롤링 허용: `/`, `/blog`, `/diagnosis`, `/calculator`, `/consultation`, `/guide`
- 크롤링 차단: `/admin`, `/api`, `/mypage`, `/auth`

## 🎯 전환 퍼널

```
1. 검색 유입 (키워드)
   ↓
2. 랜딩 페이지 (정보 제공)
   ↓
3. 도구 사용 (진단/계산기)
   ↓
4. 상담 신청 (전환)
```

### 퍼널별 최적화
- **1단계**: SEO 키워드, 메타 디스크립션
- **2단계**: 명확한 가치 제안, CTA
- **3단계**: 사용 편의성, 결과 해석
- **4단계**: 신뢰 구축, 간편한 폼
