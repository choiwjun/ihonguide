# OG (Open Graph) 이미지 가이드

이 폴더에는 각 페이지의 Open Graph 이미지가 들어갑니다.

## 필요한 이미지 파일들

각 이미지의 권장 사양:
- **크기:** 1200 x 630 픽셀
- **형식:** PNG 또는 JPG
- **파일 크기:** 100KB 이하 권장

### 필수 이미지 파일들

1. **og-default.png** - 사이트 기본 OG 이미지
   - 사이트 로고와 태그라인
   - 색상: 기본 브랜드 색상 (#0f766e)

2. **og-home.png** - 메인 페이지 OG 이미지
   - "이혼 준비 플랫폼"
   - 주요 기능 아이콘 (진단, 계산기, 상담)

3. **og-diagnosis.png** - 이혼 진단 페이지 OG 이미지
   - "이혼 유형 무료 진단"
   - 협의이혼/조정이혼/소송이혼 아이콘

4. **og-calculator.png** - 양육비 계산기 OG 이미지
   - "양육비 무료 계산기"
   - 계산기 아이콘

5. **og-consultation.png** - 상담 신청 페이지 OG 이미지
   - "이혼 전문 상담 신청"
   - 상담/변호사 아이콘

## 이미지 생성 도구

다음 온라인 도구를 사용하여 이미지를 생성할 수 있습니다:

1. **Canva (https://www.canva.com)**
   - "Social Media > Facebook Post" 템플릿 사용
   - 사이즈: 1200 x 630 픽셀

2. **Figma (https://www.figma.com)**
   - 1200 x 630 프레임 생성
   - 브랜드 색상과 폰트 적용

3. **Adobe Express (https://www.adobe.com/express)**
   - "Social Media Post" 템플릿 사용

## 브랜드 가이드라인

### 색상
- Primary: #0f766e (테이커)
- Background: #F9F8F6 (스톤)
- Text: #333333

### 폰트
- 제목: Noto Serif KR
- 본문: Pretendard

### 디자인 원칙
- 클린하고 전문적인 느낌
- 충분한 여백 유지
- 가독성 높은 텍스트
- 한글 폰트 사용

## 이미지 최적화

생성된 이미지를 최적화하세요:

1. **TinyPNG (https://tinypng.com)**
   - 파일 크기 감소
   - 품질 유지

2. **Squoosh (https://squoosh.app)**
   - 구글 제공 무료 도구
   - 다양한 포맷 변환
